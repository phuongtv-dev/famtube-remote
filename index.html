Quản lý online



  

  
Chỉnh tivi từ bất cứ đâu, không cần nhập PIN trên tivi. Tạo token trên GitHub: Settings → Developer settings → Fine-grained tokens → Generate. Repository access: chỉ repo ; Permissions → Contents: Read and write. Dán token vào đây (cho tivi) và vào trang online (cho điện thoại).

  

    
    
  

  




Sao lưu



  
Lưu toàn bộ kênh, nhóm, profile và cài đặt thành một file trên điện thoại. Ảnh đại diện và hình nền không nằm trong file sao lưu.
